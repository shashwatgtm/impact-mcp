Who is Translate Execution not ideal for?

  • Anyone who cannot give the required inputs (Positioning statement, Target customer, Key benefit); the answer is built only from them.
  • Teams that need buyer research done for them: IMPACT structures your positioning as hypotheses, and you test them with buyers.
  • Anyone who needs live competitor data: the tools look nothing up and use only what you type about your market and rivals.

How do I use Translate Execution from Claude?

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Translate Execution tool. positioning statement: For clinic operations directors who lose revenue to no-shows, ClinicFlow cuts no-shows with two-way SMS reminders.; target customer: Clinic operations directors; key benefit: Fewer no-shows; channels: ["email", "linkedin"].

MCP tool name: impact_translate_execution. REST: POST https://impact.gtmhelix.com/api/tools/impact_translate_execution with this JSON body (see Docs):

{
  "input": {
    "positioning_statement": "For clinic operations directors who lose revenue to no-shows, ClinicFlow cuts no-shows with two-way SMS reminders.",
    "target_customer": "Clinic operations directors",
    "key_benefit": "Fewer no-shows",
    "channels": [
      "email",
      "linkedin"
    ]
  }
}

How does Translate Execution work?

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
