Sector Language

Use the words buyers in cybersecurity use, and keep claims to what you can show. Words this sector's buyers use: attack surface, exposure, misconfiguration, alert fatigue, mean time to detect, mean time to respond, SOC, compliance audit, risk register, threat intelligence. What the sector measures: mean time to detect, mean time to respond, critical exposures open, alerts per analyst, audit findings, time to prepare an audit, asset coverage. A proof point that lands: Exposures found and closed during the proof of value, with the time it took to fix them.

Channel Priority

Example priorities: replace with your own. The order follows how deals usually run in cybersecurity: CISO-led, with a proof of value on the buyer's own environment; budget often follows an audit finding or an incident.

Recommended Priority Order:

  1. Cold Email (direct outreach to the roles that buy: CISO; SOC or cloud security lead)
  2. LinkedIn Organic (awareness among those same roles)
  3. Sales Deck (the story you tell once there is a meeting)
  4. Website (credibility: proof, references and the facts buyers check)
  5. Demo (proof of capability)

Who is Translate Execution not ideal for?

  • Anyone who cannot give the inputs listed above; the answer is built only from them.
  • Teams that need buyer research done for them: IMPACT structures your positioning as hypotheses, and you test them with buyers.
  • Anyone who needs live competitor data: the tools look nothing up; they work from what you type about your market and rivals, and anything they add themselves (such as common complaints in a category) is marked as something to check with buyers.

How do I use Translate Execution from Claude?

Add IMPACT once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Translate Execution tool. positioning statement: For cloud security leads at mid-size fintech companies who drown in alerts, Cloudmoat ranks every misconfiguration by real exposure so the team fixes what matters first; target customer: cloud security leads at mid-size fintech companies; key benefit: fix critical exposures first; product name: Cloudmoat.

How does Translate Execution work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run Translate Execution.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
