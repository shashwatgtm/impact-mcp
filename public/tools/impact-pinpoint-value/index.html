Use it from Claude or another assistant

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Pinpoint Value tool. target customer: Clinic operations directors; key outcome: Fewer no-shows; unique capability: Automated two-way SMS reminders; product name: ClinicFlow; customer metrics: no-shows down 30% in 3 months.

MCP tool name: impact_pinpoint_value. REST: POST https://impact.gtmhelix.com/api/tools/impact_pinpoint_value (see Docs).

How this tool works

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
