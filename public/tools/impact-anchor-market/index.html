Run Anchor Market in your browser

Required: Product description. Fields marked optional can be left empty.

Result

Use it from Claude or another assistant

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Anchor Market tool. product description: Scheduling software for clinics; potential segments: ["dental groups", "physiotherapy chains"]; average deal size: $5,000 ACV; sales cycle: 45 days.

MCP tool name: impact_anchor_market. REST: POST https://impact.gtmhelix.com/api/tools/impact_anchor_market (see Docs).

How this tool works

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
