📈 Market Sizing (Bottom-Up Calculation)

TAM/SAM/SOM for dental groups

Total Addressable Market (TAM)

TAM = Total potential customers × ACV
TAM = ~5,00,000 companies × $5,000 ACV
TAM = $2500.0M

Serviceable Addressable Market (SAM)

SAM = TAM × % that match your ICP
SAM = $2500.0M × 30% (have the problem + right profile)
SAM = $750.0M

Serviceable Obtainable Market (SOM)

SOM = SAM × Expected market share (Year 1)
SOM = $750.0M × 5%
SOM = $37.50M

Who is Anchor Market not ideal for?

  • Anyone who cannot give the required inputs (Product description); the answer is built only from them.
  • Teams that need buyer research done for them: IMPACT structures your positioning as hypotheses, and you test them with buyers.
  • Anyone who needs live competitor data: the tools look nothing up and use only what you type about your market and rivals.

How do I use Anchor Market from Claude?

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Anchor Market tool. product description: Scheduling software for clinics; potential segments: ["dental groups", "physiotherapy chains"]; average deal size: $5,000 ACV; sales cycle: 45 days.

MCP tool name: impact_anchor_market. REST: POST https://impact.gtmhelix.com/api/tools/impact_anchor_market with this JSON body (see Docs):

{
  "input": {
    "product_description": "Scheduling software for clinics",
    "potential_segments": [
      "dental groups",
      "physiotherapy chains"
    ],
    "average_deal_size": "$5,000 ACV",
    "sales_cycle": "45 days"
  }
}

How does Anchor Market work?

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
