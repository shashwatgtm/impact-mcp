Who is IMPACT Full Audit not ideal for?

  • Anyone who cannot give the inputs listed above; the answer is built only from them.
  • Teams that need buyer research done for them: IMPACT structures your positioning as hypotheses, and you test them with buyers.
  • Anyone who needs live competitor data: the tools look nothing up; they work from what you type about your market and rivals, and anything they add themselves (such as common complaints in a category) is marked as something to check with buyers.

How do I use IMPACT Full Audit from Claude?

Add IMPACT once (see Use it in Claude or ChatGPT), then ask in plain words. A prompt built from the tested example:

Use the IMPACT Full Audit tool in IMPACT. company name: Cloudmoat; product description: Cloud security monitoring for companies on AWS, Azure and Google Cloud; target customer: CISOs at mid-size fintech and SaaS companies running on two or more clouds; problem solved: Too many cloud alerts with no clear order to fix them; key differentiation: Exposure-based ranking of every misconfiguration, across AWS, Azure and Google Cloud; competitors: Competitor A, Competitor B, periodic manual audits; current positioning: Cloudmoat shows which cloud risks matter first, unlike long rule lists; customer feedback: Critical exposures down 70% in one quarter; audit preparation down from 3 weeks to 4 days.

How does IMPACT Full Audit work?

No sign-in. A web browser is enough, and the answer comes back in a second or two.

  1. Fill in the form above, or press Fill in an example.
  2. Press Run IMPACT Full Audit.
  3. Read the result on this page, then copy it and edit it before you use it.

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the AI assistant connector run the same tool code, so the same input gives the same answer in both.
