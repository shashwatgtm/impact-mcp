How do I use IMPACT Full Audit from Claude?

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's IMPACT Full Audit tool. product description: Scheduling software for clinics; target customer: Clinic operations directors; problem solved: Missed appointments; key differentiation: Two-way SMS reminders; competitors: ["Competitor A"].

MCP tool name: impact_full_audit. REST: POST https://impact.gtmhelix.com/api/tools/impact_full_audit (see Docs).

How does IMPACT Full Audit work?

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
