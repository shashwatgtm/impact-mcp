Identify Champions

Generate champion hypotheses from company/product context - no blanks, actionable insights

By Shashwat Ghosh, founder of Helix GTM Consulting · Last updated 25 September 2026

How do I run Identify Champions in my browser?

Required: Product description, Problem solved. Fields marked optional can be left empty.

Your company name

What your product does (1-2 sentences)

The core problem you solve

Type of companies you target (e.g., "Series B SaaS", "Enterprise manufacturing")

Optional: ACV range (e.g., "$50K-100K")

Result

How do I use Identify Champions from Claude?

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Identify Champions tool. product description: Scheduling software for clinics; problem solved: Missed appointments and manual rescheduling; target company type: mid-size clinic groups; price point: $400 per month.

MCP tool name: impact_identify_champions. REST: POST https://impact.gtmhelix.com/api/tools/impact_identify_champions (see Docs).

How does Identify Champions work?

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
