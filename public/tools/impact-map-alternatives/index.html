Analyze competitive landscape and find positioning whitespace

By Shashwat Ghosh, founder of Helix GTM Consulting · Last updated 25 September 2026

How do I run Map Alternatives in my browser?

Required: Your product, Category. Fields marked optional can be left empty.

What your product does

How do I use Map Alternatives from Claude?

Connect IMPACT once (see Connect), then ask in plain words. A prompt built from the tested example:

Use IMPACT's Map Alternatives tool. your product: ClinicFlow; category: clinic scheduling; competitors: ["Competitor A", "Competitor B"]; your strengths: one-day setup, SMS reminders.

MCP tool name: impact_map_alternatives. REST: POST https://impact.gtmhelix.com/api/tools/impact_map_alternatives (see Docs).

How does Map Alternatives work?

It applies fixed rules in the IMPACT code to the inputs above and returns text. It does not call an AI model, does not look anything up, and does not store what you type. The web form and the MCP server run the same function, so the same input gives the same answer in both.
