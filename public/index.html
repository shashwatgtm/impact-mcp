IMPACT

B2B positioning tools built on the IMPACT framework

Setup and toolsQuestionsPrivacySource codeAll connectors

IMPACT gives Claude eight positioning tools for B2B teams: identify champions, map alternatives, pinpoint value, anchor a market segment, craft the message, translate it into execution, run a full positioning audit, and read the IMPACT framework itself. Every tool turns the details you give it into a structured positioning draft with hypotheses to test.

Connect

Server URL

https://impact-mcp.netlify.app/mcp

Transport: Streamable HTTP (stateless, JSON responses). Authentication: none. Send MCP JSON-RPC messages with POST; other methods return 405, which is expected.

Claude (web, desktop and mobile)

  1. Open Customize, then Connectors, then Add custom connector.
  2. Name: IMPACT. MCP server URL: https://impact-mcp.netlify.app/mcp.
  3. Choose no sign-in, then Add. Turn the connector on for a chat with the + menu.

Claude Code

claude mcp add --transport http impact https://impact-mcp.netlify.app/mcp

Run it locally instead (npm, stdio)

npx -y @shashwatgtmalpha/impact-mcp

The npm package and this hosted server run the same code.

Questions and answers

What is IMPACT?

IMPACT gives Claude eight positioning tools for B2B teams: identify champions, map alternatives, pinpoint value, anchor a market segment, craft the message, translate it into execution, run a full positioning audit, and read the IMPACT framework itself. Every tool turns the details you give it into a structured positioning draft with hypotheses to test.

How do I connect IMPACT to Claude?

In Claude, open Customize, then Connectors, then Add custom connector. Name it IMPACT, paste the server URL https://impact-mcp.netlify.app/mcp, choose no sign-in and select Add. In Claude Code run: claude mcp add --transport http impact https://impact-mcp.netlify.app/mcp

Does IMPACT need an account, and what does it cost?

No account or sign-in is needed, and there is no charge. The server is public and every tool is read-only.

Which tools does IMPACT include?

8 tools: IMPACT Framework Guide, Identify Champions, Map Alternatives, Pinpoint Value, Anchor Market, Craft Message, Translate Execution, IMPACT Full Audit.

What data does IMPACT keep?

None. Each call is answered from the inputs you give it, and the server stores and logs nothing. Netlify, the host, keeps its own request logs. See the privacy policy.

Can I run IMPACT on my own computer?

Yes. Run npx -y @shashwatgtmalpha/impact-mcp to use the same tools locally over stdio; nothing is sent to us.

Who built IMPACT?

Shashwat Ghosh, founder of Helix GTM Consulting, a GTM Alpha consultant, AI GTM expert and fractional CMO with 24+ years in B2B and 10+ years of fractional experience.

Troubleshooting

  • 405 Method not allowed: you opened the server URL in a browser or sent a GET. Use an MCP client, which sends POST.
  • 429 Too many requests: the server allows 300 requests per minute from one address. Wait a minute and try again.
  • "Missing required input": the tool was called without one of the required inputs listed above.
