IMPACT docs

For developers and marketing operations teams. The decision: how to call IMPACT from your own code or assistant.

Pick a tool

Connect to the 9 MCP tools, check their input fields or call the REST API behind the web forms.

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 15 November 2026

Try these prompts

  1. Use IMPACT to identify likely champions for our cloud security monitoring platform, which ranks misconfigurations by real exposure, for mid-size fintech and SaaS companies.
  2. Map the alternatives for our cloud security monitoring platform, compared with the security tools built into each cloud provider and open-source misconfiguration scanners.
  3. Run an IMPACT full audit of our positioning: cloud security monitoring for companies on AWS, Azure and Google Cloud, target customer CISOs at mid-size fintech and SaaS companies, problem solved too many cloud alerts with no clear order to fix them.

MCP server

  • Address: https://impact.gtmhelix.com/mcp (Streamable HTTP, stateless, JSON responses). GET returns 405 by design.
  • Authentication: none. Every tool is marked read only (readOnlyHint: true, destructiveHint: false) and has a title.
  • Rate limit: 300 requests per minute per IP address. Server: impact-mcp version 2.2.27.
  • Limits: up to 262,144 bytes per call, text fields of up to 4,000 characters and one call per request (no batches). A call over a limit is refused before the tool runs.
  • Local stdio: npx -y @shashwatgtmalpha/impact-mcp. Latest npm version on 15 November 2026: 2.2.27.

REST API (used by the web forms)

Send POST https://impact.gtmhelix.com/api/tools/<tool name> with a JSON body {"input": {...}}. The answer is JSON: {"ok": true, "tool": "...", "title": "...", "text": "..."}, where text is the same Markdown the MCP tool returns. The endpoint calls the same server code as the MCP address.

Terminal
curl -s -X POST https://impact.gtmhelix.com/api/tools/impact_get_framework \
  -H "Content-Type: application/json" \
  -d '{"input": {"focus_phase": "all"}}'
  • Errors: 400 with errors (missing or invalid fields), 404 for an unknown tool, 405 for methods other than POST, 413 above 32,000 bytes, 422 when the tool itself refuses the input (ok is false and error holds the tool's message), 429 when the rate limit is reached, 500 if the tool fails.
  • Limits: 30 requests per minute per IP address, up to 32,000 bytes for the whole request, up to 6,000 characters for each top level text field and up to 50 items for each top level list.
  • Forms without JavaScript post application/x-www-form-urlencoded and get an HTML page back.
  • Inputs and answers are not stored, and the input is not logged (see Privacy).

Tool reference

From hosted tools/list on 15 November 2026, version 2.2.27. A dot marks a field inside an object and [] marks an array item. Required fields inside an optional object apply when that object is supplied.

IMPACT Framework Guide

impact_get_framework

Helps you decide which positioning steps to run, and in what order. You give nothing, or one IMPACT step to focus on and your sector. You get the IMPACT positioning method step by step (identify champions, map alternatives, pinpoint value, anchor in a market, craft the message, translate it to execution), with a template or checklist for each step; a focus step returns that step only, and your sector adds its buyer roles, measures and proof points.

FieldTypeRequiredAllowed valuesMeaning
focus_phasestringnoidentify, map, pinpoint, anchor, craft, translate, allSpecific phase to focus on (identify/map/pinpoint/anchor/craft/translate)
sectorstringnoYour sector in your own words (for example logistics tech, fintech, SaaS, vertical SaaS, AI native, IT services, telecom, software or cybersecurity). Adds how the six steps read in that sector. The same as your selected sector; your selected sector wins when both are given
your_sectorstringnologistics_tech, fintech, saas, vertical_saas, ai_native, ites, telecom, software, cybersecurity, otherYour company's own industry (not your customers'). When given, it decides the sector notes; when left out, the tool reads it from your words and stays neutral if they are unclear.

Identify Champions

impact_identify_champions

Helps you decide who inside the buyer will push for you. You give what your product does and the problem it solves, plus optional company name, target company type, price point and sector. You get hypotheses for the champion, the economic buyer, the technical influencer, commercial and control reviewers and daily users, warning signs of an anti champion, a path to develop the champion and what to give them. These are roles to test, not named people.

Anchor Market

impact_anchor_market

Helps you decide which market segment to win first. You give what your product does and the segments you are weighing, plus optional customers, pain, deal size and company counts. You get a beachhead choice: your segments ranked from your own customers, pain and deal size when you give all three (the answer says which method it used), otherwise scored on keywords in their names; a TAM, SAM and SOM calculation from only the figures you give; a three year expansion path and an ICP hypothesis for the chosen segment. It never chooses a segment you did not name.

current_customersstringnoDescription of your current/best customers. With customer pain and average deal size it ranks the segments (the answer says which method it used); without them it is shown only and the keyword presets score the segments

IMPACT Full Audit

impact_full_audit

Helps you decide whether your positioning is working and what to fix first. Use for a full positioning review or when someone asks help me explain why we are different. Ask what the product does, who it serves and the problem it solves before calling; never invent these or fill missing facts with placeholders such as Not supplied. Clarify what unlabelled numbers mean. For a request only to phrase a message, impact_craft_message also fits; use this tool for the full review. You get input completeness scores, supplied proof, a positioning draft and next actions. Scores measure how complete the inputs are, not how strong the positioning is. Never invent proof.

FieldTypeRequiredAllowed valuesMeaning
company_namestringnoYour company name
product_descriptionstringyesWhat the product or service does, in the user's words. Ask if missing; do not invent or use a placeholder.
target_customerstringyesWho it serves, as supplied by the user. Ask if missing. Keep staff ranges as ranges and clarify unlabelled numbers.
problem_solvedstringyesThe problem the user says they solve. Ask if missing; do not invent or use a placeholder.
key_differentiationstringnoA difference the user can describe. Leave out if unknown; do not invent uniqueness or proof.
competitorsarray of stringnoMain competitors
current_positioningstringnoYour current positioning statement or tagline
customer_feedbackstringnoCustomer feedback actually supplied by the user. Leave out if absent; never invent quotes or outcomes.
business_modelstringnosaas, services, connectivity, transactions, marketplace, hardware_software, investmentHow you sell (saas, services, connectivity, transactions, marketplace, hardware_software or investment). Used in the plan; read from your inputs when not given. It does not change the score
your_sectorstringnologistics_tech, fintech, saas, vertical_saas, ai_native, ites, telecom, software, cybersecurity, otherYour company's own industry (not your customers'). When given, it decides the sector notes; when left out, the tool reads it from your words and stays neutral if they are unclear.

Build our message for this segment

Build our message for this segment when our sellers do not use the message or buyers stay with what they have. Needs the product, segment, champion problem, alternatives, outcome, capability and proof. Returns proof gaps and current approach questions, champion and alternatives maps for human choices, then a message and proof plan after a pause. Optional agreed workshop claim is the starting point. Without a real customer result, buyer lines are unproved hypotheses and the next step is discovery questions. Chat carries the brief between calls.

How to read the answer

Both the MCP server and the REST endpoint return the same structured Markdown text for a given input object, or an HTTP 400 error listing any missing or invalid fields. Inside the returned Markdown, positioning steps follow fixed rules, bracketed placeholders mark missing facts, and any unprovided benchmark is labelled as an example figure.

What to do next

  • Founder: Test Full Audit or Identify Champions via the MCP endpoint or REST API with your real product, customer, and problem details.
  • CEO: Review the input fields for Anchor Market and Full Audit so your team supplies real competitor and customer feedback.
  • CMO: Use the schemas for all six IMPACT steps to standardize how product marketing documents champions, alternatives, value, and messaging.
  • CRO: Check the fields for Map Alternatives, Pinpoint Value, and Translate Execution so sales enablement includes real deal alternatives.
  • Demand generation head: Pass your target channels and audience into Craft Message and Translate Execution.

Why come back

Come back when you wire IMPACT into an internal workflow, check allowed enum values, or review the latest release notes. The tool applies the same fixed rules every time. It does not call an AI model, and this site does not keep what you enter.
