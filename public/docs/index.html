For developers

IMPACT docs

The MCP address, the REST API behind the web forms, and every field of all 8 tools.

By Shashwat Ghosh, Co-Founder and Fractional CMO, Helix GTM Consulting · Last updated 2 October 2026

Try these prompts

  1. Use IMPACT to identify likely champions for Cloudmoat, cloud security monitoring that ranks misconfigurations by real exposure, for mid-size fintech and SaaS companies.
  2. Map the alternatives for Cloudmoat in the cloud security monitoring category, compared with Competitor A and Competitor B.
  3. Run an IMPACT full audit of our positioning: cloud security monitoring for companies on AWS, Azure and Google Cloud, target customer CISOs at mid-size fintech and SaaS companies, problem solved too many cloud alerts with no clear order to fix them.

MCP server

  • Address: https://impact.gtmhelix.com/mcp (Streamable HTTP, stateless, JSON responses). GET returns 405 by design.
  • Authentication: none. Every tool is marked read-only (readOnlyHint: true, destructiveHint: false) and has a title.
  • Rate limit: 300 requests per minute per IP address. Server: impact-mcp version 2.2.27.
  • Limits: 262,144 bytes per call; text fields up to 4,000 characters; one call per request (no batches). A call over a limit is refused before the tool runs.
  • Local use: npx -y @shashwatgtmalpha/impact-mcp runs these tools over stdio (npm can lag behind this site until a new version is published).

REST API (used by the web forms)

Send POST https://impact.gtmhelix.com/api/tools/<tool name> with a JSON body {"input": {...}}. The answer is JSON: {"ok": true, "tool": "...", "title": "...", "text": "..."}, where text is the same Markdown the MCP tool returns. The endpoint calls the same server code as the MCP address.

Terminal
curl -s -X POST https://impact.gtmhelix.com/api/tools/impact_get_framework \
  -H "Content-Type: application/json" \
  -d '{"input": {"focus_phase": "all"}}'
  • Errors: 400 with errors (missing or invalid fields), 404 for an unknown tool, 405 for methods other than POST, 413 above 32,000 bytes, 422 when the tool itself refuses the input (ok is false and error holds the tool's message), 429 when the rate limit is reached, 500 if the tool fails.
  • Limits: 30 requests per minute per IP address; the whole request up to 32,000 bytes; top-level text fields up to 6,000 characters and top-level lists up to 50 items.
  • Forms without JavaScript post application/x-www-form-urlencoded and get an HTML page back.
  • Nothing is stored and the input is not logged (see Privacy).

Tool reference

Generated from the server's own input schemas, version 2.2.27.

IMPACT Framework Guide

impact_get_framework

Returns the IMPACT positioning method step by step: identify champions, map alternatives, pinpoint value, anchor in a market, craft the message and translate it to execution, with a template or checklist for each step. An optional focus phase returns one step only, and your sector adds that sector's buyer roles, measures and proof points. Open the form.

FieldTypeRequiredAllowed valuesMeaning
focus_phasestringnoidentify, map, pinpoint, anchor, craft, translate, allOptional: specific phase to focus on (identify/map/pinpoint/anchor/craft/translate)
your_sectorstringnologistics_tech, fintech, saas, vertical_saas, ai_native, ites, telecom, software, cybersecurity, otherYour company's own industry (not your customers'). When given, it decides the sector notes; when left out, the tool reads it from your words and stays neutral if they are unclear.

Identify Champions

impact_identify_champions

Takes what your product does and the problem it solves, and returns hypotheses for who buys it: the champion, the economic buyer, the technical influencer, commercial and control reviewers and daily users, with warning signs of an anti-champion, a path to develop the champion and what to give them. Optional company name, target company type, price point and sector fit the roles to your market. These are roles to test, not named people. Open the form.

Map Alternatives

impact_map_alternatives

Takes your product and its category, and returns a map of the alternatives your buyers weigh: one card for each competitor you name, the status-quo options you list and doing nothing, where you can lead, and discovery questions to learn more. Optional competitor weaknesses and your strengths fill the cards, and your sector adds its questions and objections. It uses only what you give and says what would sharpen the map. Open the form.

Anchor Market

impact_anchor_market

Takes what your product does and the segments you are weighing, and returns a beachhead market choice: your segments ranked from your own customers, pain and deal size when you give all three (the answer says which method it used), otherwise scored on keywords in their names; a TAM/SAM/SOM calculation that uses only the company counts, deal size and percentages you give; a three-year expansion path and an ICP hypothesis for the chosen segment. It never chooses a segment you did not name: without segments it recommends none and explains how to find yours from your own customers. Open the form.

current_customersstringnoOptional: Description of your current/best customers. Shown in the output; not used in the scoring

When given, it decides the sector notes; when left out, the tool reads it from your words and stays neutral if they are unclear.

Optional channels, product name and business model shape it. Open the form.

IMPACT Full Audit

impact_full_audit

Takes what your product does, your target customer and the problem you solve, and returns a positioning audit: an input completeness score for each IMPACT step, the proof you already have, your current positioning checked in words, a recommended positioning with tagline options, a 30-day action plan and the measures to track. Optional company name, differentiation, competitors, current positioning, customer feedback and business model make it fuller. The score measures how complete your inputs are, not how strong your positioning is. Open the form.
